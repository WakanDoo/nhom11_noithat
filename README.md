* Nguyễn Viết Nam: Chịu trách nhiệm định hướng giao diện tổng thể, triển khai Trang chủ và trang Công trình, đảm bảo tính nhất quán UI/UX toàn hệ thống.

* Lê Thị Hải Nhi: Phát triển Trang liên hệ và trải nghiệm 3D; phụ trách thiết kế UI các trang chính (Liên hệ, About, 3D) và triển khai responsive cho toàn bộ hệ thống.

* Đỗ Quốc Khánh: Phát triển các tính năng xác thực (đăng nhập/đăng ký) và module 3D; chịu trách nhiệm cấu hình, build và triển khai hệ thống lên môi trường production.

* Trần Quốc Huy: Phát triển Trang giỏ hàng và thanh toán; thiết kế và tối ưu trải nghiệm checkout.

* Đỗ Thị Yến Nhi: Phát triển Trang chi tiết sản phẩm và About; đảm bảo hoàn thiện giao diện và tính đồng bộ giữa các thành phần.

Hoạt động chung của nhóm:

* Xây dựng ý tưởng và định hướng sản phẩm
* Phân tích người dùng và kịch bản sử dụng
* Xây dựng hệ thống nhận diện thương hiệu (logo, màu sắc, font)
* Review thiết kế và kiểm thử chức năng
* Fix bug và tối ưu trải nghiệm

## 2. Tổng quan dự án

**Lĩnh vực:** Nội thất & Thương mại điện tử

**Thương hiệu:** OWLHOME

OWLHOME là một nền tảng website nội thất hiện đại, được xây dựng nhằm mang đến trải nghiệm số hóa trong việc khám phá và lựa chọn sản phẩm nội thất. Dự án tập trung vào việc kết hợp giữa thiết kế tối giản và kiến trúc frontend hiện đại để đảm bảo hiệu năng cao và trải nghiệm người dùng tối ưu.

Website đóng vai trò như một showroom trực tuyến, cho phép người dùng dễ dàng duyệt sản phẩm, tìm kiếm và tương tác trong một giao diện trực quan và nhất quán.

---

## 3. Tính năng nổi bật

* Giao diện responsive trên nhiều thiết bị (desktop, tablet, mobile)
* Tối ưu hiệu năng với công nghệ frontend hiện đại
* Hệ thống tìm kiếm sản phẩm
* Điều hướng rõ ràng, trải nghiệm người dùng thân thiện
* Trang trải nghiệm nội thất 3D cho phép người dùng tương tác và hình dung không gian thực tế

## 6. Hướng dẫn chạy local

### Yêu cầu

* Node.js >= 16

### Cài đặt

```bash
npm install
```

### Chạy dự án

```bash
npm run dev
```

Truy cập tại:

```
http://localhost:3000
```
